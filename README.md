# Склад Ezhi

Каталог продавца **Ezhi** с барахолки Дизель-форума (diesel.elcat.kg) с поиском и корзинами:
https://risabd.github.io/ezhi/

Своего сервера нет: форум отдаёт страницы с `Access-Control-Allow-Origin: *`, поэтому страница сама скачивает
темы продавца и разбирает посты прямо в браузере.

- **Каталог.** Сначала показывается последний сохранённый: из кеша браузера или снимок `docs/data/catalog.json`,
  смотря что свежее. Если он старше 3 часов, страница в фоне обходит 12 тем форума (около 10 секунд) и обновляется.
  Если в это время что-то ищете или листаете, появится кнопка «каталог обновлён — показать».
- **Снимок** обновляет GitHub Actions каждые 3 часа (`.github/workflows/pages.yml`), он же выкладывает сайт.
- **Фото** грузятся прямо с форума.
- **«в посте ↗»** — копия поста продавца с подсветкой строки товара (`post.html`). Страница форума берётся
  из кеша браузера, а если её там нет — с форума.
- **Корзины** хранятся в браузере (localStorage). Кнопка со ссылкой копирует ссылку, в которой зашита вся
  корзина (`#c=<id>.<id>*2&n=<название>&m=<заметка>`, id укорочены до однозначных 7 знаков), — она откроется
  в любом браузере и сохранится там к себе.

## Файлы

- `docs/` — сайт: `index.html` (поиск и корзины), `post.html` (копия поста), `ezhi.js` (обход форума, разбор
  постов, кеш, корзины-ссылки), `data/catalog.json` (снимок).
- `ezhi_catalog.py` — тот же разбор на Python (только стандартная библиотека):

  ```sh
  python3 ezhi_catalog.py snapshot --refresh   # снимок для сайта → docs/data/catalog.json
  python3 ezhi_catalog.py crawl                # полный каталог в catalog.json / .csv / .md (страницы кешируются в cache/)
  python3 ezhi_catalog.py search tp4056 "pro mini"
  ```

- `tools/check_parity.sh` — сверка `ezhi.js` с `ezhi_catalog.py` на одних и тех же страницах из `cache/`
  (headless Chrome): число товаров, id и все поля должны совпасть. Запускать после правок разбора.
- `tools/live.html` — живая проверка: браузер сам качает форум и обходит все темы.

Локально: `python3 -m http.server -d docs 8000` и открыть http://localhost:8000 (кеш браузера работает
только на https или localhost).
